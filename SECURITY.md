# Security policy

Only the latest default-branch version is supported. Trace input can be sensitive
and is untrusted. Redact it before analysis. Fixture isolation is cooperative,
not a security sandbox. Model outputs cannot authorize actions.

For a vulnerability, use GitHub's private vulnerability reporting on this
repository when available. Otherwise contact the maintainer through the contact
method on their GitHub profile to arrange private disclosure. Do not include
credentials or private traces in public issues. General bugs belong in issues.
