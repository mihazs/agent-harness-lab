# Community conduct

Be respectful, constructive and specific. Harassment, discriminatory abuse,
threats and disclosure of another person's private information are unacceptable.
Critique work and evidence rather than people.

Report conduct concerns privately using the maintainer contact described in
SECURITY.md. The maintainer may remove content, close discussions or restrict
participation proportionately, and will handle reports discreetly. These standards
apply to project issues, pull requests and other official project spaces.
