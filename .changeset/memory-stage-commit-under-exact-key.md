The memory store can now hold the outputs the stage reuse planner decides on. `agent_harness_lab.memory.commit` is the one writer and verifier of the `ahl-stage-record-v1` record and its `stage_records` index, shared with `ahl analyze --incremental`: it publishes a deterministic stage's output and appends one record (stage, exact node key, components, status, output, per-stage `sequence`) under that key (idempotent; another output under a committed key is refused), keeps a typed diagnostic event for a failed or interrupted stage that is never returned as reusable, and stores a frozen `ahl-stage-reuse-v1` receipt only when it lists every stage and keeps `reused_live_trials: 0` and `publication_allowed: false`. Committers of one project serialize on a bounded per-project lock (256 lock files, busy timeout from the store), which also keeps `sequence` unique. Lookup re-verifies the record against its hash, key and index row on every read, and records survive `reindex`. A stage committed by either path is reused by the other. Loading the latest record of every stage for the whole graph remains. Part of #633; builds on #635.
