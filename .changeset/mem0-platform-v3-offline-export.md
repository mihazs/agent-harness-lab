Add the offline `mem0-platform-export` source for one selected Mem0 Platform v3 get-all page sequence plus per-memory history. It is a separate source version with its own profile and identity namespace. Pagination is bounded and flagged when truncated or inconsistent, `app_id` and `session_id` scopes, user-or-assistant OR listings and history scope fields are honoured, replaced and deleted memories stay in evidence but leave the currently-asserted count, and no memory becomes a task outcome. No hosted API, token or network is used.
