`ahl improve --correction-excerpts` (off by default) gives the proposer session up to 12 bounded, scrubbed excerpts of your own recorded user messages from this project in which you corrected the agent, written to the private `user-corrections.json`, and also reads sessions of unverified runtime versions for them. Without the flag no user text reaches any run artifact.
