AHL's own preparation sessions (the proposer and the evaluation author) now run as pure as the trials: Claude Code gets project-only setting sources, a strict empty MCP config, hooks disabled and a staged write grant with read access to the run directory and the project, plus only AHL's own plugin; Codex gets a temporary `CODEX_HOME` with `--ignore-user-config` and `--ignore-rules`. Codex sessions, preparation and trials, use your saved subscription login instead of requiring `CODEX_API_KEY`: `auth.json` is copied into the temporary home with mode `0600` for the length of the run and deleted after it, a token the run refreshed is written back atomically only when the real file is still what was copied, and receipts record only `subscription_login_copied`, `subscription_login_refreshed` or `not_staged`. A saved login takes precedence over `CODEX_API_KEY`, which is removed from the session environment so it cannot bill the API. New opt-in `--with-user-harness` on `ahl improve`, `ahl watch` and `ahl skills invoke` runs the trials of both arms under your installed harness (Claude Code keeps your settings, plugins, hooks and MCP servers; Codex keeps the real `CODEX_HOME`) for a more precise evaluation; preparation stays pure, and the run and every trial record `user_harness`.
