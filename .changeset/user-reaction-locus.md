The analysis brief gains a `user_reactions` section: where users intervened (steering mid-work, a follow-up after the agent stopped, a revert, reopen or restated instruction), located by the agent's last tool, command family and file extensions, as closed-vocabulary tokens and counts only. The proposer of an installing `ahl improve` run is told to start from those rows. A session capture over the remaining byte budget is now skipped instead of ending the read, so a few large recent sessions no longer hide every older one.
