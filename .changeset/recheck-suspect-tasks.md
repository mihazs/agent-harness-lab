When both arms of an installing run fail a claim task with the identical stated grader reason, the evaluation author rechecks those tasks once, with the same candidate, before the result can steer a refinement; the trial ceiling of an unconfigured run rises to 100 to leave room for it. A refinement after a rejected first candidate now gets the measured feedback instead of the rejection prompt and a reset candidate. Fixtures may no longer name absolute paths outside the workspace.
