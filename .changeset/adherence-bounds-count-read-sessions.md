Fix the instruction-adherence report never reaching `completed` on a project with many subagent transcripts. The 200-file and 512 MiB bounds of the native reader were charged to every file in path order, including subagent and foreign-project files that are turned away at their first row, so on real histories the bounds were used up before any main session was tried and the brief said `not_run` / `no_readable_native_session`. The bounds now charge only the captures that were really read (the skipped files are still counted by reason), and `ahl analyze` offers the most recently written captures first, so the bound keeps the recent sessions. `ahl analyze PROJECT --history-from CHECKOUT` now judges the sessions recorded under that checkout instead of calling every one of them `foreign_project`, which made the report impossible to complete for a linked worktree. A run that a bound stopped before any session was read now says `read_bound_reached` instead of `no_readable_native_session`.
