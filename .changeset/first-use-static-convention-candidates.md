Give a first `ahl improve --history` run something to evaluate when the history has findings but no verified outcome. The run now audits the project itself (read-only, bounded, no model call) and stages the best eligible static convention (a truncated or oversized instruction chain, a skill routing collision, an instruction chain above the 200-line convention or a procedure-shaped section) as a hypothesis labelled `hypothesis_source: static_convention`, with its finding id and convention source, evaluated in the normal paired flow and never applied; `static_convention_candidates` lists the conventions left for a later run. When nothing is eligible the run ends with the first-use `no_outcome_evidence` block without a model call, and `findings_not_candidates.static_audit` states why; when the instruction chain cannot be settled (for example Codex without a Git project root or an unresolved Claude import) the cause is `instruction_totals_unsettled` with its reasons and lists only the conventions actually checked, never a clean result. The spend label is the single `spend_label`/`spent_without_evaluation` receipt of the first-use gate. Runs with a verified outcome, `--focus` or `--from-audit` keep their candidate path. The automatic seed is recorded in `provenance.agent_supplied_hypothesis` as `static_audit`, and no candidate of that run is independent corroboration.
