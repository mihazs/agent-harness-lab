Nested-surface adoption now checks what it writes, not only where. `candidate_states` and `Journal.prepare` classify a changed file with its execute bits, so an executable `.claude/rules/*.md` or a suffix-less script in a nested skill bundle needs the hook contract. An agent definition whose Claude frontmatter or Codex role file registers hooks also needs it, and an undecodable, escaped or unparsable definition fails closed. A rollback no longer breaks when a `.git` appears below the project after adoption, while a new promotion of the now-nested file is still refused.
