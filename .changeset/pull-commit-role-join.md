Add an offline PR commit-role join. It names the roles an exact local commit holds in one GitHub pull request (head, base, merge result, test merge or listed member) from native PR edges in the latest checkpoint. A head recorded only in an earlier checkpoint is reported as superseded, so a stale head never counts as current. A missing edge stays unknown and never becomes unlinked, and the private report carries only candidate receipts with no outcome or authority.
