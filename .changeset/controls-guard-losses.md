In an installing run a regression control blocks only when the candidate breaks it (the baseline passed it and the candidate failed it); a control the baseline itself fails no longer withholds a gain. A pruned candidate that still passes the tasks attempt 0 showed fixed goes to the fresh-repeat confirmation instead of being decided by one more run of an intermittent baseline.
 A first proposer that declines no longer uses up the refinement attempt: the retry is the first measured attempt and keeps its own refinement.
