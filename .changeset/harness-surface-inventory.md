Add `agent_harness_lab/sources/harness_inventory.py` and `ahl sources inventory`, a read-only inventory of the harness surface files in one checkout. It walks the checkout without following links and refuses symlinks, special files, `.git`, nested repositories and hard-linked surface files. Every regular file that `surfaces.classify` recognizes becomes a node with its kind, scope, content hash, mode, declared state, parse status, trust and a capability reference. `observed_loading` and `effective` are always `unknown`. Node path identities match `HarnessFile`, and an optional Git `inventory_profile` binds the inventory to the captured `HarnessSnapshot` without changing its fingerprint. Bounds are 1000 nodes, 10 MiB, depth 32 and 20000 entries. Going over any of them gives `blocked`, never a truncated result. Roots outside the checkout are read only when the caller declares them, and those nodes are labelled `caller_declared_external`. Project trust is a declaration that defaults to `unknown`. Parsers register in a sorted `PARSERS` tuple and are all stubs in this release. The CLI writes to a private `0700` XDG state directory with `publication_allowed: false`.
