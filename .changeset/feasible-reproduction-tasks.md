The evaluation author is told to build only tasks one non-interactive trial session can complete with sequential tool calls inside the per-trial limit (no background or concurrent processes, wall-clock timing, network, credentials, human replies or other agents). A live task that required work done while a suite ran in the background failed both arms by construction. The task text must also never forbid a step its grader requires: a live task forbade installing packages while its grader required installed git hooks.

A live installing run ended inconclusive because its first proposer declined before anything was measured; an installing run now asks one more proposer for its strongest candidate. A fixed held-out task now counts as a gain to confirm in an installing run (only development tasks counted, so a live candidate that fixed the reproduced weakness was discarded).
