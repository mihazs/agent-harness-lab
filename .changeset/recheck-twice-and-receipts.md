A run may recheck suspect tasks twice, since a rebuilt evaluation can carry a defect of its own. After a lost task is dismissed by its repeats, the before/after comparison in the receipt no longer calls the run regressed. The install reviewer works in a folder outside the run output. The evaluation author is told that a grader may only require names, strings or formats the task states. An installing run no longer ends blocked when a root instruction edit carries an optional instruction plan that does not validate; the plan is ignored and the evaluation decides.
