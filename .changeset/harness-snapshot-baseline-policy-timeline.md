Give every harness a precise identity and a timeline. `ahl memory snapshot --checkout DIR --runtime R --version V` prints a path-free `snapshot_id` over the declared surface files (bytes, modes, surface class and scope), the refused entries, the declared runtime and the declared trust, so the same bytes give the same id in any directory and any relevant surface change gives a new one; `ahl memory diff --from-snapshot A --to-snapshot B` lists added, removed and modified surfaces by path hash with `cause: not_established`. A snapshot bound to a Git `HarnessSnapshot` records its commit only as an annotation (`files_match_commit`, `uncommitted_changes` or `unknown`, always `ignored_state: not_captured`), never as the identity. The new `agent_harness_lab.memory.harness_history` module adds closed-field timeline events (`harness_changed`, `evaluation_completed`, `evaluation_invalidated`, `source_gap`, `grader_quarantined`, `baseline_reselected`, `regression_retested`) with instant, origin and an authoritative pointer and no cause field, logical change-set associations, and baseline policies: a `predeclared_fixed_reference` is refused when an outcome of its subject was already recorded, `previous_valid` and `rolling_window` are descriptive, and reselecting a baseline records `baseline_reselected` and yields a descriptive policy that can never upgrade the original claim. Documents publish into the memory store as immutable artifacts and `timeline` refuses a truncated listing.
