Add `agent_harness_lab/sources/agents_inventory.py`, a declared inventory of Claude Code `.claude/agents/**/*.md` and Codex `.codex/agents/**/*.toml` custom agent definitions, plus caller-declared user, plugin and `CODEX_HOME` roots. A new bounded frontmatter reader, `sources/frontmatter.py`, reports Claude skip reasons (`no_leading_fence`, `bad_yaml`, `missing_name`, `invalid_name`, `missing_description`). It flags unknown fields as `ignored_by_runtime`, checks the `omitClaudeMd` and `autoCompactWindow` version gates against the declared version, and marks plugin-only ignored fields as `ignored_for_plugin_agents`. Codex role files are parsed with `tomllib`. They need a name, a description and non-blank `developer_instructions`. Unknown keys are `unknown_field_rejected`, and `sandbox_mode`, `approval_policy`, `model_provider` and `mcp_servers` are `no_override_effect`. Same-layer duplicates are warned, and an untrusted project layer is `gated`. Precedence labels are declared only: no definition is reported as available or loaded, and load timing stays `unverified`. Agent files now classify as kind `agent` with the hook contract facet, so their changes are never adoptable and embedded hooks are listed for hook classification instead of being executed.
