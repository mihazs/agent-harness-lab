Add `ahl trace-import --format atif --input FILE --output NEW_DIRECTORY`, a bounded offline importer that converts one named ATIF-v1.8 trajectory into content-free AHL telemetry events (`events.v2.jsonl`, source format `atif`) and a loss report (`conversion-report.json`) in a new private directory. A field-level mapping table (`agent_harness_lab/interop/mapping.py`, rendered in `docs/atif-import-reference.md`) decides what each field becomes: step order, timestamps, roles, token counts (uncached input is prompt minus cached, and is withheld when the cached share is absent), digested tool names, call identifiers, model and agent, and declared embedded-subagent parent links. Message bodies, reasoning, tool arguments and results, costs, `final_metrics` totals and every `extra` object are dropped and counted by path, never recorded. Imported evidence leaves the task outcome `unknown` and lineage unverified: nothing in a trajectory, including forged grade labels in `extra`, can create a verified result or independence. Unsupported schema versions, malformed or oversized structure, duplicate keys, nonfinite numbers, invalid timestamps and reference cycles are rejected with a typed reason and nothing is written; unmatched, duplicate or unreferenced calls and unsupported media, file-path subagent references and continuation references are represented as explicit incomplete evidence and never opened, fetched or followed. Part of #38; the OpenTelemetry serialization and any ATIF export remain follow-up slices.
